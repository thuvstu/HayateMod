# UI・街・量産の実機検証手順

前提: `./gradlew :mod:runClient`、チートONサバイバル。

## U1 画面
- `/solommo market` → 画面が開き価格・在庫が見える。買1/買8/売1/売8が動く。
- `/solommo craft` → 一覧＋作れるものが有効表示。作る→入手。
- `/solommo loadout` → キー切替（街の外では不可のはず）、保存（名前入力）、適用。
- `/solommo tavern` → 名簿＋雇用費＋突入ボタン。
- `/solommo codex` → 所持武器と一致数が並ぶ。

## U2 HUD
- 武器を持って `G` → ホットバー下に特技名＋CDバーが出て減る。
- `/solommo dungeon enter` → 左上にパーティ欄（自分＋NPC3人のHP%）が出る。
- ボス戦でフェーズが変わるとボスバー名に P2 が付く。

## U3 街・量産・釣り
- `/solommo town` → 集落へ移動（屋台・井戸・村人3人）。`/solommo back` で戻る。
- 街の外で `/solommo loadout load X` → 拒否メッセージ。
- 野外で2分待つ → 雑魚が湧く（名前＋Lv表示つき）。
- 釣り竿で釣る → 釣果でXP（`/solommo mine` では出ない点に注意。釣りLv表示は未実装）。
- 新武器7＋1が `/solommo give` とクリエイティブに出る。アースシェイカーの
  特技（範囲強打）をダミーで試す。

## 報告
- 開かない画面・押せないボタン・変な表示があれば手順つきで。
