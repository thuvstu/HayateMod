# P2/3 実機検証手順（実アイテム・RPG体力・効果エンジン）

前提: `./gradlew runClient`、チートON、サバイバル。`run/logs/latest.log` で `[RPG]` を確認。

## P0 起動時
- ログに `[content] loaded from ... weapons=1 skills=8 ...` が出る。
- `/s1 status` のHP表示は従来通り。

## P1 アイテム取得・表示
- `/solommo give solommo:ember_branch` → 投槍が手に入り、ツールチップに名前・IL・
  「突き（火、射程4、幅0.35）」「単発投射（火、射程24、CD3秒、消費スタミナ10）」
  「命中時：対象が燃焼状態の場合、…2発放つ…」が出る。
- `/solommo codex` → `solommo:ember_branch` が記録される。

## P2 特技と分裂（灰枝槍を持つこと）
- `/s4 dummy` でダミー召喚 → `G` で火弾。ダミーに命中で炎上はしないが
  エンジン側 ignite が付く（ログ `[RPG]` 参照）。
- CD中に `G` → チャットに CD 残り時間。
- 燃焼中のダミー（1発当てて5秒以内）にもう1発 → 追加で2発分裂する。
- 素手殴り（武器なし）→ バニラダメージのまま。槍を持って殴る → エンジン近接
  （`[RPG][MELEE]` がログに出る）。

## P3 RPG体力
- ダメージを受けるとハートが RPG HP 比率で減る（バニラ20をミラー）。
- 自然回復・再生で RPG HP が回復する（`[S1][HEAL]` と RPG 残量が連動）。
- HP0 → バニラ死亡する（ワイプ・チェックポイントは Phase 4）。

## P4 ドロップ・交換
- ゾンビを倒す → 素材（craft_material）が落ちる。
- `/solommo shards 12` → `/solommo exchange` → 灰枝槍と交換できる。
- ワールド再起動後も `/solommo codex` が残っている。

## P5 リロード
- `content/` の YAML を少し変えて `/solommo reload` → ログに再読込。
  失敗時は旧データを維持する（わざと壊して確認可、要復元）。

## 既知の割り切り
- プレイヤーのみ RPG HP（Mob はバニラ HP）。
- ゾンビ→煤テーブルはスパイク対応（正式な敵スポーン紐付けは Phase 4）。
- 死亡時ドロップあり（救済・チェックポイントは Phase 4/6）。
- クリエイティブでも RPG 処理が走る場合がある。
- shield ON 中の火弾は敵をすり抜ける（見た目のみ）。
