# ADR-14: Phase 6 ゲームロジック（市場・採掘・進行ループ）

日付: 2026-10-07
状態: 採用（テスト37件＋ビルド＋起動確認。実機は `docs/p6-test.md` で検証待ち）

## NPC市場（§5.14）
- 式どおり：`price = base × (target/max(stock,1))^elasticity`、0.3〜3.0倍制限。
  売値 = 価格×(1-spread)、買値 = 価格。往復で必ず損（裁定なし）をsimとテストで確認。
- 市場日は12,000tickごとの専用カウンタ（`dayTime`不使用・オフライン不進行）。
  在庫＋カウンタはワールドJSONに永続化。
- 通貨はバニラのエメラルド（新規通貨アイテムを作らない判断。修理・雇用など
  将来の使い道もエメラルド建てで統一できる）。
- 欠片は取引不可（進行保全。検証器V02で禁止）。
- 通貨吸収：売買スプレッド、ダンジョン雇用費（エメラルド5/入場）、クラフト費。

## 採掘スキル（§5.14）
- 鉱石ごとのXP＋到達表（Lv5鉄解禁・Lv10弱点・Lv15宝石枠・Lv20危険鉱山）。
  数値は暫定（鉄10xp・Lv5=200xpなど）。実測で調整する。
- 鉄系はLv5未満で破壊キャンセル（設計どおり）。バニラドロップは不変。
- Lv15以上でダイヤ・エメラルド鉱石から素材+1（宝石枠の最小実装）。
- `lifeskills.json` に永続化。`PlayerProfileStore` 抽象化は将来（§7.1）。

## 進行ループ（§4.2）
- フィールド（採掘XP・素材・Mob素材）→ 市場（売却→エメラルド）→
  クラフト/交換 → ダンジョン（雇用費）→ 図鑑、がコマンド経由で一巡する。
- `/solommo mine` で採掘状態を確認できる。

## 残課題（MVP判定まで）
- UI画面（戦闘バー・酒場・市場・図鑑などのScreen。現状コマンドのみ）。
- コンテンツ量（レア7・ユニーク3・生活2種目・地域など）。
- A2/A3/A4/A5/A7/A8 の計測（テレメトリ未整備）。A1/A6(2本)/A9(部分)/A10は対応済み。
- 難易度ルールセットの上位差分（§5.15。normalのみ）。
