# ADR-15: UI画面・量産・街（MVP残件の前倒し）

日付: 2026-10-07
状態: 採用（テスト34件＋ビルド＋起動確認。実機は `docs/ui-test.md` で検証待ち）

## UI（バニラScreen＋HUD、ライブラリ不使用）
- 画面5種：市場・工房（クラフト＋分解）・ロードアウト・酒場・図鑑。
  サーバー権威：画面はS2Cペイロードで開き、操作はC2Sで検証つき実行。
  新規ペイロード14種（S2C 6＋C2S 8）。チャットコマンドも併存。
- HUD：スキルCD（HOTBAR下）＋パーティフレーム（BOSS_BAR下）。
  CDはサーバー決定値の表示のみ（検証はサーバー）。
- ボスバー名にフェーズ表示（自動同期）。
- 教訓：レコードComponent `id` は外側static `id(String)` を隠蔽する。
  定義ファイル側は `UiPayloads.id(...)` と明示修飾すること。

## 量産
- レア7（槍2・剣3・杖2、固定値・IL5〜18、field/boss分類タグ付き）。
  アフィックス乱数は未導入（§5.9の小ランダムは将来）。
- ユニーク3本目 `solommo:earthshaker`（範囲強打剣）。A6の変化要件に対応。
- 釣り：`FishingHook.retrieve` Mixinで釣果XP＋到達表。鉱石同様JSON永続（新旧両対応）。

## 街（陽炎の集落）
- 地形追従の高床プラットフォーム＋3屋台（作業台系ブロック付き）＋井戸＋
  フェンス＋松明＋常駐村人3人。`/solommo town/back` で往復。
- ロードアウト切替とダンジョン入場は街限定（S2等の直接起動は除外）。
- フィールドスポーナー：2分毎に雑魚（上限3・96m外は消去）、2%でネームド。
  `solommo_wild` タグでアリーナスイープと区別し、報酬は通常適用。

## 残課題
- 市場・酒場などのScreen見た目は最小限（装飾なし）。
- 街の拡張（2地域目以降はAlpha）。
- G1/S2/S3/A系列の実機判定はユーザ実施待ち。
