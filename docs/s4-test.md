# S4 実機検証手順（戦闘の手触り・G0判定材料）

前提: `./gradlew runClient`、チートON、平らな場所（スーパーフラット推奨・サバイバル）。
ログ: `run/logs/latest.log` の `[S4]` で確認。

## S4-1 ダミー召喚
- `/s4 dummy` → 目の前に「訓練用ダミー」（動かないゾンビ、HP200）とボスバーが出る。
- 合格: 召喚・名札・ボスバー表示。

## S4-2 火弾スキル
- `G`キー → 火の玉が飛ぶ。ダミーに当てるとボスバーが減り、ログに `[SKILL]` と funnel の `src=fireball` が出る。
- 合格: キー入力→C2S→サーバーで発射→ダメージの一連が動く。

## S4-3 クールダウン
- `G` を連打 → 2発目はチャットに `[S4] CD中` と出て発射されない。
- 合格: サーバー側でCD検証している（クライアントの言いなりで発射しない）。

## S4-4 範囲攻撃と予兆
- ダミーの近くに15秒立つ → チャット警告＋炎のパーティクル円（2秒）→ 円内にいると6ダメージ、離れれば回避。
- 合格: 予兆→着弾→回避の一連が読み取れる。円が見づらい／避けられない等の感想も記録。

## S4-5 10分プレイ（G0の核心）
- ダミーを倒すまで戦う（火弾のみ、HP200）。
- 報告: 「この戦闘を続けたいか・作り続けたいか」（Yes/No＋理由）。
  手触りの違和感（弾速・硬直・音・視認性）もあれば書く。

## 既知の割り切り（スパイクのため）
- 予兆はパーティクルのみ。クライアント描画の円・扇との比較は後続スパイク。
- ダメージはバニラ値（RPG式は Phase 2）。数値の良し悪しではなく操作感だけ見る。
