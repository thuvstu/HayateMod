# サバイバル通しテスト（チートなし新規ワールド推奨）

前提: `./gradlew :mod:runClient`、**チートなし**サバイバル新規ワールド。

## V1 最初の一歩
- `/solommo town` で集落へ（権限不要のはず。op要求が出たら報告）。
- 村人に右クリック：モカ→酒場、ドン→工房、ピパ→市場が開く。
- ゾンビを素手で倒す → 素材が落ちる。武器なしでも進行できること。

## V2 市場と採掘
- 石炭・鉄を掘る → `/solommo mine` でLv確認。鉄はLv5まで掘れない。
- `/solommo market sell ...` で売却 → エメラルド入手 → 素材を購入。
- 素材が貯まったら `/solommo craft solommo:cinder_pike`（素材24）。

## V3 ダンジョン
- エメラルド5以上を持って酒場主人から入場（雇用費が引かれる）。
- NPC3人とゴーレム戦。倒す → キーストーン入手メッセージ。
- `/solommo keystone ...` で装備（未所持は断られる）。
- `/solommo dungeon exit` で撤退。`/solommo back` で集落へ。

## V4 進行確認
- `/solommo codex` → 入手品が並ぶ。再起動後も残る。
- 釣り竿で釣る → たまにXP（レベルは `/solommo mine` には出ない点に注意）。

## 報告
- op要求・クラッシュ・進行不能があれば手順つきで。通せたらMVP判定の材料にする。
